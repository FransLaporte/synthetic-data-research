\section{Introduction}\label{sec:intro}
Autonomous vehicles rely on perception models that interpret sensor data, and for LiDAR a common perception task is semantic segmentation, in which every point of a scan is assigned a class such as car, road or pedestrian. Training these models requires large datasets in which every point is labelled, and producing such datasets is costly, as the annotation of the SemanticKITTI benchmark alone required more than 1700 hours of work~\cite{behleySemanticKITTIDatasetSemantic2019}. Synthetic data generated in simulation can be labelled automatically and offers control over the content of each scene~\cite{hurlPreciseSyntheticImage2019,xiaoTransferLearningSynthetic2022}. It nevertheless differs from real sensor measurements, and this difference, known as the domain gap, can limit how well a model trained on synthetic data performs on real data~\cite{hurlPreciseSyntheticImage2019,manivasagamLiDARsimRealisticLiDAR2020}.

Our literature review found that synthetic datasets and simulators such as PreSIL, LiDARsim and SynLiDAR transfer usefully to real data only in particular settings, for instance when the synthetic scans are followed by fine-tuning on real scans, when the simulator reproduces real sensor effects such as missing returns, or when domain adaptation is applied~\cite{hurlPreciseSyntheticImage2019,manivasagamLiDARsimRealisticLiDAR2020,xiaoTransferLearningSynthetic2022}. The value of a synthetic dataset therefore has to be established for each case, and the most direct evidence of this value is the performance on held-out real data of a model trained on it, referred to in this proposal as downstream performance. This performance is measured with the intersection over union (IoU) of each class, which is the overlap between the predicted and true labels divided by their union, and with its average over all classes, the mIoU. Both can also be computed within distance ranges, which reveals losses on small or distant objects.

Because a model has to be trained and evaluated for every candidate dataset, generated scans are commonly assessed with data-level diagnostics instead, which compare synthetic scans directly with real scans~\cite{zyrianovLearningGenerateRealistic2022}. This proposal considers the three diagnostics that were used to evaluate the generative model LiDARGen~\cite{zyrianovLearningGenerateRealistic2022}, for which a lower value indicates that the two sets are more similar. The \emph{Fr\'echet range distance} (FRD) compares the features that the pretrained segmentation network RangeNet++~\cite{miliotoRangeNet++Fast2019} extracts from both sets, thereby measuring whether the network responds to both sets in a similar way. The \emph{maximum mean discrepancy} (MMD) and the \emph{Jensen--Shannon distance} (JSD) compare where the points are located around the sensor, using bird's-eye-view (BEV) maps that count the points in each cell of a top-down grid. MMD compares the maps of individual scans, whereas JSD compares the summed maps of both sets. Each diagnostic summarises a complete set of scans in a single value, so a loss of performance that is limited to small or distant objects may not be reflected in it.

Whether the diagnostics can replace real-data evaluation thus depends on how closely they follow downstream performance. To our knowledge, no study has quantified how far synthetic data must deviate from real data before the diagnostics register the deviation, compared with the deviation at which downstream performance starts to decline. The proposed study addresses this gap with a controlled experiment in which ray drop is applied to a synthetic dataset in increasing steps and both the diagnostics and the mIoU are measured at every step. Ray drop refers to emitted laser pulses for which no return is measured, an effect that occurs in real sensors but is absent from basic simulations~\cite{manivasagamLiDARsimRealisticLiDAR2020}. The results are expected to show, for this type of deviation, to what extent a favourable diagnostic score can justify omitting real-data evaluation.
