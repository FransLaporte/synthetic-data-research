# Starting sources to screen

These are verified source leads, not a completed search or a set of included
studies. Read the full papers, apply the protocol and create study records
before drawing conclusions. Import new sources through Zotero before citing
them in LaTeX; the existing bibliography is not modified by this list.

- [Alaa et al., How Faithful is your Synthetic Data? (2022)](https://proceedings.mlr.press/v162/alaa22a.html):
  fidelity, diversity and generalization framework. Existing citation key:
  `alaaHowFaithfulYour2022`.
- [Heusel et al., GANs Trained by a Two Time-Scale Update Rule (2017)](https://arxiv.org/abs/1706.08500):
  starting source for FID.
- [Binkowski et al., Demystifying MMD GANs (2018)](https://arxiv.org/abs/1801.01401):
  starting source for KID and kernel-based evaluation.
- [Tobin et al., Domain Randomization for Transferring Deep Neural Networks from Simulation to the Real World (2017)](https://arxiv.org/abs/1703.06907):
  vision transfer case for examining variation and realism requirements.

Extend the search for label quality, scenario coverage, subgroup bias and
real-test utility; this seed list does not cover all research questions.
