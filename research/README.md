# Review records

These notes support the paper but are not included in the PDF automatically.

- `templates/search.md`: copy to `searches/YYYY-MM-DD-database-author.md`.
- `templates/study.md`: copy to `studies/<citation-key>.md`.
- `seed_sources.md`: starting leads, not an included-study list.

Create `searches/` and `studies/` when adding the first records. Keep one file
per search or study. Link study records to the search that discovered them.
Record actual counts and decisions; blank templates are not completed work.
Verify extraction with the other author before using it in the synthesis.
